# Library-Management-System📚

This is a program written with the help of Python (IDLE) and MySql both.💻 It helps maintaining a database of all types of library records.🪈

‼️ Your Python editor must be connected to your MySql database before you run this code ‼️

For example:

-> Adding records ➕

-> Updating records 📚

-> Searching records 🔎

-> Deleting records 🚫

It creates two separate tables for books📔 and for users👥.
